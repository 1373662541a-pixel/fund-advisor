# 基金投资分析助手（Fund Advisor）

个人基金持仓分析工具：上传/维护持仓 → 展示大盘行情与 AI 分析 → **每个交易日 14:30 自动生成当日操作建议**。

## 核心功能（v1.2.0）

- **持仓管理**：截图识别导入（AI 视觉 + 本地 OCR 双引擎）、CSV/Excel 导入、手动增删改
- **截图自动推算**：识别「持有金额 + 持有收益率」后，按当日净值自动推算持有份额与成本净值
- **持仓 × 建议融合表格**：每只基金一行，同时展示份额/成本、最新净值、今日/近 1 月/近 3 月涨跌、累计盈亏、占比与操作信号
- **加仓 / 减仓**：提交操作金额后，**下一个交易日自动按当日净值结算**并同步重算 AI 建议与总结
- **自动同步**：任何持仓变更（增删改/导入）都会自动刷新操作建议
- **AI 解读**：可选接入 DeepSeek / 通义千问，生成更智能的操作建议文案

## 快速开始

服务已在本机运行：**http://127.0.0.1:3081**

手动启动 / 重启：

```bash
cd /root/fund-advisor
npm start            # 前台启动（或 nohup node server/index.js &）
```

后台由 `fund_advisor_daemon.sh` 保活，进程挂掉会自动拉起（日志：`/tmp/fund_advisor.log`、`/tmp/fund_advisor_daemon.log`）。

## 使用流程

1. **录入持仓**（三种方式任选）：
   - 「📷 识别持仓截图」：从相册选择支付宝/天天基金/银行 App 的持仓截图，自动识别出基金列表，核对并补全「持有份额」「成本净值」后确认导入。
      **识别双引擎**（弹窗会标明本次所用方式）：
      - **AI 视觉识别（推荐）**：在「设置」中启用并填入 API Key 后，调用视觉大模型直接读图——默认通义千问 `qwen-vl-max`（DashScope 兼容模式），也兼容 GPT-4o、GLM-4V 等任意 OpenAI 风格视觉接口；准确率高、速度快（5~15 秒），直接输出代码/名称/份额/成本；
      - **本地 OCR（兜底）**：tesseract.js（chi_sim+eng，字库缓存在 `data/`，无外传），未配置 AI 时自动使用；首次需加载中文字库约 1 分钟。
      识别结果支持两种方式（弹窗里会标明每只基金的识别方式）：
     - **按代码**：截图里有 6 位基金代码，直接查证（本地 2.7 万+ 基金库，含场内 ETF/LOF）；
     - **按名称**：截图只有基金名称（如支付宝持仓主列表）也能识别——内置全部基金名称库，支持简称、去括号（如"招商中证白酒指数A"→161725）、场内场外命名倒序（"华泰柏瑞沪深300ETF"→510300）、以及常见 OCR 错字容错；
     - **代码+名称**：两者互相印证，置信度最高。
   - 「⬆ 上传 CSV/Excel」：下载模板 `template.csv` 填写后上传，同代码重复上传会合并更新份额/成本；
   - 「＋ 添加持仓」：逐条手动添加（输入 6 位基金代码可自动查询名称/净值）。
2. **查看分析**：页面展示大盘行情、今日建议（综合评分、操作要点、风险提示、单基金信号）、资产分布饼图，以及持仓 × 建议融合表格（份额/成本 + 净值/涨跌/盈亏/操作信号同排展示）。
3. **生成建议**：每个交易日 14:30 自动生成；也可随时点右上角「⚡ 立即生成今日建议」（当日已生成时会询问是否覆盖）。**持仓有任何增删改/导入操作时，建议会自动同步重算**。
4. **加仓 / 减仓**：持仓表格每行有「＋加仓 / －减仓」按钮，输入操作金额（元，可任意小数）后提交，页面顶部会提示"预计 X 生效"；**下一个交易日服务自动按当日净值结算**——加仓按净值折算份额并加权更新成本净值，减仓按净值扣减份额（超过持仓金额视为全部赎回），结算完成后 AI 建议与总结自动重算刷新。
5. **历史建议**：底部按日期列出，点击可回看任意一天。
6. **设置**：仅保留「风险偏好」（保守/稳健/进取）与「建议每日生成时间」两项；AI/视觉 API Key 在首次配置后保存在本机 `data/settings.json`，页面不会展示、保存设置时也不会覆盖已配置的 Key。

## AI 解读（可选）

内置规则引擎开箱即用（基于大盘涨跌、基金估值/净值趋势、持仓盈亏、集中度打分）。如需更智能的文案：

1. 到 https://platform.deepseek.com 申请 API Key；
2. 页面「设置」中勾选「启用 DeepSeek AI 解读」，填入 Key（模型默认 `deepseek-chat`），保存；
3. 之后每次生成建议会自动附上 AI 解读；Key 只存在本机 `data/settings.json`，不会外传。

## 隐私与安全

- 服务仅监听 `127.0.0.1`，只允许本机访问。
- 所有运行时数据（持仓、设置、API Key、建议历史、节假日、基金库）均存放在 `data/` 目录，**该目录已被 `.gitignore` 排除，不会进入 Git 仓库/上传 GitHub**。
- 代码中不包含任何硬编码密钥；AI/视觉 API Key 通过页面设置后保存在本机 `data/settings.json`，仅在本机使用、绝不外传。
- 截图识别默认调用本地 OCR（tesseract.js，图片不出本机）；启用 AI 视觉时，截图会发送到您配置的视觉大模型接口用于识别。
- 部署到新环境后，请先访问页面「设置」或直接编辑 `data/settings.json` 填入您自己的 API Key。

## 数据来源与交易日

- 大盘行情：东方财富行情接口（上证/深成/创业板/沪深300/中证500）
- 基金净值/历史净值：腾讯基金行情 + 东方财富基金数据
- 盘中估值：腾讯/新浪基金接口（仅交易时段内可信，拿不到时回退到最近净值并明确标注）
- 截图识别：**AI 视觉模型（可选，推荐）** 或 tesseract.js 本地 OCR（chi_sim+eng，字库缓存在 `data/`，无外传）+ 本地基金名称库（`data/funds.json`，可用 `npm run funds` 重新同步）
- 交易日历：官方节假日安排（`data/holidays.json`，可用 `npm run holidays` 重新同步；也可手动编辑该文件增删）

调度逻辑：上海时区；周末与节假日不生成；`14:30` 触发后至 `17:00` 前若当日未生成会补生成；服务当时若未运行，下次启动且仍在窗口内会补生成。

## 数据文件（都在 data/ 目录）

| 文件 | 内容 |
| --- | --- |
| `holdings.json` | 持仓（代码/份额/成本/备注） |
| `settings.json` | 设置（风险偏好/调度/AI Key） |
| `advice.json` | 每日建议历史 |
| `holidays.json` | 节假日日历 |

## 常用命令

```bash
npm start                       # 启动服务
node scripts/run-now.js         # 命令行立即生成今日建议
node scripts/run-now.js --force # 强制覆盖今日建议
npm run holidays                # 重新同步节假日日历
npm run funds                   # 重新同步基金名称库（场外 + 场内 ETF）
```

## 注意事项

- 仅监听 127.0.0.1，只允许本机访问。
- 服务依赖外网数据接口，行情/估值失败时会降级（标注原因），不影响其余功能。
- 建议为规则模型与公开数据自动生成，**仅供参考，不构成投资建议**；基金有风险，投资需谨慎。
